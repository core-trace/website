# Agente CoreTrace para Linux

Extraia todo o ZIP e abra um terminal na pasta `agente`.

## Instalar

É necessário ter Python 3 com suporte a ambientes virtuais (venv), acesso à internet e permissão para escrever nesta pasta

Execute uma vez:

```bash
bash instalar.sh
```

A instalação cria a pasta `.venv` aqui e instala as bibliotecas necessárias.

## Iniciar

```bash
bash iniciar.sh
```
